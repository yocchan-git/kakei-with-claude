# /setup — 初回セットアップ（非エンジニア向け・Claude が代行）

このスキルの目的は、**利用者に難しいことをさせないこと**。
コマンドや設定ファイルの編集は Claude が代行し、人にしかできない操作（Web 画面でボタンを押す等）だけを、画面の場所まで具体的に案内する。

> 前提: 利用者は非エンジニア。専門用語を避け、1 ステップずつ「次にやること」を 1 つだけ提示する。
> 各ファイルへの書き込み前は必ず内容を見せて「これで保存していいですか？」と確認する。

## ステップ 0: あいさつと全体像

「これから 5 分くらいで初期設定をします。順番に1つずつ進めます」と伝え、以下を案内する流れを共有する：
1. 必要部品のインストール 2. 通知の設定 3. カレンダー連携（任意・推奨） 4. 目標の設定 5. 初月の予算づくり

## ステップ 1: 依存パッケージのインストール

- `npm install` を実行する（Claude が代行）。エラーが出たら内容をかみ砕いて説明する。
- `node --version` が無ければ「Node.js のインストール」を案内（https://nodejs.org/ja の LTS）。

## ステップ 2: 個人設定ファイル `config.json`

- `config.example.json` を読み、`config.json` を作成する（Claude が代行）。
- `projectPath` は**このフォルダの絶対パス**に置き換える（`pwd` で取得）。
- `csv.filePattern` は既定でマネーフォワード ME に対応。別の家計簿アプリを使う場合は、利用者にダウンロードした CSV のファイル名を 1 つ教えてもらい、それに合う正規表現を Claude が組んで設定する。
- `categories` は初期カテゴリの叩き台（後で /month-start で調整可）。

## ステップ 3: 通知の設定（`.env`）— 既定は Discord

- `.env.example` をコピーして `.env` を作る（Claude が代行）。
- **Discord（推奨・いちばん簡単）**の場合、こう案内する：
  1. Discord アプリを開く → 通知を受け取りたいサーバーを用意（無ければ「サーバーを追加」で自分用に作る）
  2. 「サーバー設定」→「連携サービス」→「ウェブフック」→「新しいウェブフック」
  3. 「ウェブフックURLをコピー」を押す
  4. コピーした URL をこのチャットに貼ってもらう
- 受け取った URL を `.env` の `DISCORD_WEBHOOK_URL=` に Claude が書き込む（書き込み前に確認）。
- Slack / Chatwork を希望する場合のみ、それぞれの取得手順を案内して該当変数に書く。
- 設定後、`npm run reminder:weekly -- --force` で**テスト送信**し、実際に届くか一緒に確認する。

> 注意: `.env` は秘密情報。`.gitignore` 済みで GitHub には上がらないことを利用者に伝えて安心させる。

## ステップ 4: カレンダー連携（任意・推奨）

支出に影響する予定（旅行・飲み会・美容など）を予算に自動で反映できるので**連携を推奨**する。

- Claude Code の Google カレンダー連携が使えるか確認する（`/mcp` の一覧に Google Calendar 系があるか、`mcp__*Calendar*` ツールが見えるか）。
- 無ければ「Claude Code で Google カレンダーと連携すると、予定に合わせて予算を自動調整できます。連携しますか？」と案内し、接続フロー（`/mcp` から認証）を促す。
- 連携しない場合でも全機能は動く（予定の自動反映だけスキップ）と伝えて先へ進む。

## ステップ 5: 目標の設定（`data/TARGETS.md`）

- `data/TARGETS.example.md` を読み、`data/TARGETS.md` を作成する（Claude が代行）。
- 利用者に対話で聞く（数字は概算で OK と伝える）：
  - 毎月の手取り収入（家計に使える額）
  - 目標の貯蓄率（例: 20%）。イメージしづらければ「毎月いくら貯めたいか」で聞いて率に換算する。
- 聞いた値で TARGETS.md を埋めて保存（確認後）。

## ステップ 6: 初月の予算づくりへ

- 「準備完了です。さっそく今月の予算を作りましょう」と伝え、続けて **`/month-start` の手順を実行**する（同じ会話の中でそのまま進めてよい）。

## 完了メッセージ

セットアップ完了後、利用者に次の運用を一言で伝える：
- 毎月 1 日ごろ「/month-start」で予算を立てる
- 週の区切り（7・14・21・月末）に通知が来たら CSV を落として「/weekly」で予実チェック
- 通知の自動化（毎日決まった時刻にリマインド）を希望するなら、README「リマインダーの自動化」の手順を案内する
